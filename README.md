# Open-Scaling

Upscaler de tela em tempo real usando **Vulkan** e **AMD FSR (FidelityFX Super Resolution)**.
Projeto pessoal, ainda em **beta**, bugs conhecidos estão sendo corrigidos aos poucos.

> ⚠️ **Compatibilidade:** roda apenas em **XFCE / X11**. Wayland e outros ambientes não são suportados no momento.

## Status

- 🚧 Em desenvolvimento ativo (beta)
- 🐛 Bugs conhecidos ainda não corrigidos (mouse e input no geral ainda quebrados)
- ⚡ Sem garantia de funcionamento estável ou direto
